# Step 5 Preprocess and Split

This folder contains the preprocessing and split deliverables.

## Deliverables

- `scripts/sample_holdout.py`: cleans raw text, removes duplicates/empty rows, recreates the generated holdout from the locked original, creates train/test files, and writes descriptive stats.
- `data/original_holdout_1000.csv`: locked hand-labeled holdout source. Do not edit or regenerate this file.
- `data/holdout_1000.csv`: generated 1,000-row holdout recreated from `original_holdout_1000.csv`.
- `data/holdout_1000_balanced.csv`: existing balanced holdout artifact.
- `data/train_test_15000.csv`: combined train/test pool generated by the script, targeting 15,000 rows when enough cleaned raw text is available.
- `data/train.csv`: training split generated by the script.
- `data/test.csv`: test split generated by the script.
- `data/preprocess_split_summary.txt`: length stats, sample summaries, and imbalance plan generated by the script.

## Run

From the project root:

```bash
python step5_preprocess_split/scripts/sample_holdout.py
```

The script reads `step4_dataset_collection/data/sentences_raw.csv` and the locked `step5_preprocess_split/data/original_holdout_1000.csv`, then writes generated Step 5 outputs into `step5_preprocess_split/data/`. It never writes to `original_holdout_1000.csv`.

The current cleaned raw file has fewer than 16,000 usable unique sentences, so the generated train/test pool documents the shortfall in `data/preprocess_split_summary.txt`.

## Imbalance Handling

The holdout is fixed from the hand-labeled original so labels remain reproducible. The train/test files are balanced as much as possible by industry, ticker, and filing year. After labels are available, report class distributions and rely on macro F1, MCC, class weighting, or balanced sampling if rare classes appear.
