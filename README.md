# Team 8 Capstone Workflow

This repository is organized by project step and deliverable.

## Folder Map

- `step3_data_source_plan/`: data source justification and sampling approach.
- `step4_dataset_collection/`: SEC EDGAR collection scripts and raw sentence dataset.
- `step5_preprocess_split/`: preprocessing, locked holdout sampling, train/test split files, and descriptive stats.
- `step6_human_labeling/`: human-labeled holdout, consensus labels, and reliability report.
- `step7_genai_benchmark/`: GenAI labeling script, model label files, benchmark notebook, metrics, and cost/time summaries.

Run scripts from the project root unless a step README says otherwise.
